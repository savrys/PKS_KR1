#  СБПз - Система бронирования посещений зоопарка

Консольное приложение на языке Java для управления бронированием посещений зоопарка. Разработано в рамках контрольной работы №1 по дисциплине "Разработка консольной информационной системы на Java".

Описание предметной области

Система предназначена для автоматизации процесса бронирования билетов в зоопарк.

## Основные участники:

Посетитель - клиент, который хочет забронировать посещение.

Бронирование - заявка на посещение зоопарка с указанием даты, количества билетов и статуса.

# Приложение реализует следующие возможности:

## Управление посетителями:

-Добавление нового посетителя

-Просмотр списка всех посетителей

## Управление бронированиями:

-Создание бронирования

-Просмотр всех бронирований

-Удаление бронирования

## Поиск и фильтрация:

-Поиск бронирований по имени посетителя

-Фильтрация по диапазону/дат посещения

## Статистика:

-Общее количество посетителей

-Общее количество бронирований

-Количество бронирований по каждому статусу

-Количество крупных бронирований (3+ билета)
